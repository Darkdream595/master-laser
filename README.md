## 🎮 操作

| 输入 | 作用 |
|---|---|
| 🖐️ 按住左半屏（翻盖）拖动 | 往左拉展开，往右推合上。开得越大，光束越长 |
| ⌨️ `←` / `→` 按住 | 持续展开 / 合上 |
| ␣ `Space` | 菜单：打开简介；简介：下一页；结算：再来一局 |
| ⎋ `Esc` | 简介中：跳过并开始 |
| ⏸️ `P` | 暂停 / 继续 |
| 💤 切到后台 | 自动暂停，回来按 `P` 继续 |

松手时如果离端点很近，翻盖会磁吸到全开或全合，并带一下回弹 (๑•̀ㅂ•́)و✧

**开局流程**

1. 主菜单点「开合开始」，或按 `Space`
2. 看 6 页玩法简介：折痕光剑 → 串水果 → 躲炸弹 → 连串回血 → 激光超载 → 超载有次数（随时可以「跳过并开始」）
3. **3‑2‑1 倒计时**后弹出「开串！」。倒计时期间可以先调好开合度，这时不抛水果，也不计超载充能
4. 结算页点「再来一局」会直接进倒计时，不再重放简介

## 📱 这台手机

- 🔧 右半机身固定，内屏是**战场**，光束从折痕（战场左缘）水平射出
- 📖 左半机身是翻盖：展开时内屏显示 **HUD**，合上时背面外屏显示战场
- 📏 光束长度：全合时约为战场宽的 **12%**，全开时约 **94%**
- 🪟 翻盖半开时，左片画面会变糊、变暗（悬浮玻璃逆投影模糊）。想看清 HUD 只能全开
- 🎨 机身有两种配色可选：**炭金黑 / 月光白**，选择会被记住

## 🍉 水果与炸弹

水果和炸弹从战场下方沿抛物线抛上来，**上升时穿过一次光束线，落回时再穿一次**，一共两次判定机会 (◕ᴗ◕✿)

| 情况 | 结果 |
|---|---|
| 🍢 水果穿线时碰到光束任意位置（根部到尖端都算） | 串到，得分 |
| 🍃 水果没被串到，掉出战场 | 漏接，**‑5 血** |
| 💥 炸弹穿线时碰到光束任意位置 | 爆炸，**‑20 血**，红闪 + 整机震动 0.5 秒，屏幕多一道裂纹 |
| 😎 炸弹从光束尖端外飞过，或掉出战场 | 不扣血 |
| 💚 炸弹进过光束正上方的绿光带（擦弹带），之后从尖端外穿过光束线、没被引爆 | **擦弹，+1 血**（满血只提示），每颗炸弹最多一次 |
| 🏓 水果或炸弹碰到左右边缘 | 反弹回来（保留 80% 水平速度），始终不会飞出屏幕 |

> [!TIP]
> 看到炸弹就合上 (ﾉ>ω<)ﾉ 炸弹总落在偏右的位置，而且一定在最短光束的尖端之外，合到最短一定躲得开。

⏱️ **生成节奏**：开局每 1.5 秒抛 1 个，120 秒内逐渐加快到每 0.55 秒 1 个；45 秒后每次还有 20% 的概率多抛 1 个。约 16% 是炸弹。

## 💯 计分与连击

- 每串到 1 个，得 `10 × 连击倍率` 分
- 2 秒内连续串到，倍率 +1，**最高 ×5** 🔥；超过 2 秒没串到，倍率归零
- 超载期间得分再 **×2**
- 🏆 历史最佳存在浏览器本地（localStorage）

---

## 💚 血量与连串回血

- ❤️ 血量 **100**，显示在 HUD 的「生命 · 光液」玻璃管里，状态栏的电量也就是血量
- 🔗 **连串**：连续串到，中间没被炸弹炸到也没有漏接。和连击不同，连串不限时间
- 🩹 连串达到 3 个以后，每多串 1 个回 1 血（满血不再回）
- 🪽 **擦弹**：炸弹压到光束上方的绿光带后，及时收短光束让它从尖端外落下，回 1 血。不影响连击和连串（超载时光束横贯全屏，炸弹一穿线就熔掉，不会出现擦弹）
- 😱 连串中被打断会一次性重罚，连串清零：

| 打断方式 | 平时 | 连串 ≥ 3 时 |
|---|---|---|
| 💣 炸到炸弹 | ‑20 | **‑25** |
| 🍃 漏接水果 | ‑5 | **‑10** |

> 📊 模拟器测试结果：一直全开不动，约 40 秒被炸死；一直合上，约 37 秒因为漏接而死。挂机活不下来 (´・ω・`)

## ⚡ 激光超载

- 🔋 **充能**：完整开合 **6 次**就会触发。合上 → 全开 → 合上（或反过来）算 1 次，每碰到一个端点算半次。战场顶部的 6 颗菱形是充能进度
- 💫 **效果（5 秒）**：光束锁定满长并**射穿右屏**，碰到的炸弹直接熔掉，不扣血也不打断连串，得分 ×2 ✧*｡٩(ˊᗜˋ*)و✧*｡
- 🔥 **代价 1：右缘烧穿**。每超载一次，战场右缘就多烧掉一块，还会出现坏线和裂纹，整局都在
- 😵 **代价 2：屏幕过热（超载结束后 3 秒）**
  - 整个画面蒙上一层模糊，手机开着合着都一样
  - 水果数量变成平时的 **3 倍**（只多加水果，真炸弹数量不变）
  - **所有东西都显示成炸弹**，看外观分不出来
  - 伪装成炸弹的水果：串到照常得分，漏掉不扣血；真炸弹照样扣血

---

## ☠️ 超载次数与手机报废

- 每局只能超载 **3 次**，菱形右侧的「剩 N」就是剩余次数
- 次数用完后，⚡ 图标变成 ☠️，菱形变成朱砂红
- 💀 **次数为 0 时再攒满 6 次开合，手机直接报废**，血再多也没用 (╯°□°）╯︵ ┻━┻
- ♻️ **恢复**：连串每满 15 个（15、30、45…）恢复 1 次，上限 3 次

---

## 🏝️ 随机事件：应用孤岛

- 🎲 **触发**：开局或上次事件结束后冷却 **15 秒**；冷却结束后，每次从合上状态开始展开，有 **35%** 的概率触发
- 📵 **表现**：翻开后，游戏不会铺满两块内屏，只在折痕正中开出一块单屏宽的窗口，里面就是合上时的完整竖屏画面，窗口两侧全黑。合上时外屏视野完整，所以要翻开才发现
- 🔦 **判定照常**：黑区里看不到水果，但还会有水果抛出来，激光也照常判定
- ⏩ **结束**：全开再合上算 1 回合，第 **3** 次合上后恢复正常。开合越快，越早结束
- 🔔 触发时弹通知「🏝️ 应用孤岛 · 此应用尚未适配折叠屏 · 合上 3 次恢复」

## 🖥️ HUD 一览

**展开后左屏**

| 组件 | 含义 |
|---|---|
| 🕐 时钟 / 日期 | 真实的系统时间 |
| ⭕ 战况 · 穿刺（战况环） | 红环：连击倍率；绿环：离历史最佳还差多少；黄环：连击窗口剩余时间 |
| 🍢 最近串到 | 最近串到的 6 个水果和本局总数 |
| 🧪 生命 · 光液 | 玻璃管里的光液：满血是熔金色，残血是朱砂红。受击会晃，回血时管壁泛绿 |

**战场顶部（合上也看得到）**：顶部胶囊 + 超载充能行（菱形 + 「剩 N」）。合上时多显示一条精简血条，展开后它会淡出，充能行随之上移，避免和左屏血条重复。

## 🎛️ 调参速查

所有数值都在 [`js/config.js`](js/config.js)，**改完保存、刷新页面就生效** (￣▽￣)ノ

| 键 | 默认值 | 作用 |
|---|---|---|
| ⭐ `BOMB_CHANCE` | `0.16` | 炸弹概率；设成 `0` 就是纯水果休闲模式 |
| ⭐ `DRAG_FLAP_SPAN` | `1.5` | 拖动灵敏度：拖过 单片宽 × 该值 = 从全合到全开 |
| `HP_MAX` | `100` | 血量 |
| `DMG_BOMB` / `DMG_MISS` | `20` / `5` | 炸弹 / 漏接扣血 |
| `DMG_BOMB_STREAK` / `DMG_MISS_STREAK` | `25` / `10` | 连串中被打断的重罚 |
| `GRAZE_H` / `GRAZE_HEAL` | `30` / `1` | 擦弹带高度 px（设 `0` 关闭擦弹）/ 每次擦弹回血 |
| `COMBO_WINDOW` / `COMBO_MAX` | `2.0` / `5` | 连击窗口 s / 倍率上限 |
| `SPAWN_INTERVAL0` → `SPAWN_INTERVAL_MIN` | `1.5` → `0.55` | 生成间隔，在 `SPAWN_RAMP_TIME = 120` 秒内逐渐加快 |
| `WALL_BOUNCE` | `0.8` | 碰左右边缘后保留的水平速度比例 |
| `BUZZ_TIME` / `BUZZ_AMP` / `BUZZ_HZ` | `0.5` / `8` / `18` | 被炸震动的时长 s / 幅度 px / 频率 |
| `OVERLOAD_CYCLES` / `OVERLOAD_TIME` | `6` / `5` | 触发超载需要的开合次数 / 持续 s |
| `OVERLOAD_CHARGES` / `OVERLOAD_RESTORE_STREAK` | `3` / `15` | 每局超载次数 / 连串多少个恢复 1 次 |
| `OVERLOAD_BLUR_TIME` / `BLUR_FRUIT_MULT` | `3` / `3` | 过热模糊时长 s / 期间水果倍数 |
| `ISLE_COOLDOWN` / `ISLE_CHANCE` / `ISLE_ROUNDS` | `15` / `0.35` / `3` | 应用孤岛：冷却 s / 触发概率 / 持续回合 |
| `GLASS_SPREAD` / `GLASS_DARK` | `0.42` / `0.001` | 悬浮玻璃的模糊扩散 / 变暗强度（着色器移植自 MIT 项目，见 `THIRD_PARTY_NOTICES`） |
| `BEST_KEY` | `crease_pierce_best_v1` | localStorage 键名（沿用旧名以保留历史最佳）；改名等于清空所有人的历史最佳 |


## 🧭 开发约定

1. 🚫 **零依赖、零构建、零网络请求**：不引入 npm、打包器、CDN、外部字体或图片
2. 🚫 **不改成 ES Modules**：在 `file://` 下 `import` 会被 CORS 拦截，双击就跑不起来了
3. 🧱 **职责分离**：`game.js` 不碰 DOM 和 canvas，`render.js` 不改游戏数值，魔法数字统一放进 `CFG`
4. 😀 emoji 依赖系统字体，不同平台外观有差异，这是预期行为
5. 💾 `file://` 和 `http://` 下的 localStorage 互相隔离，换一种打开方式，历史最佳会「消失」
